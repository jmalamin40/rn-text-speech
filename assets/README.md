# Assets Folder

## Logo File

### Option 1: Local Logo File (Recommended)
Place your logo image here with the filename: `logo.png`

**Logo Requirements:**
- **Format**: PNG (recommended) or JPG
- **Size**: 512x512 pixels (square) for best quality
- **Background**: Transparent PNG works best
- **File name**: `logo.png` (must be exactly this name)

### Option 2: Remote Logo URL
If you prefer to use a remote logo URL, edit `App.tsx`:
1. Comment out the local image line
2. Uncomment the remote URL option
3. Replace the URL with your logo URL

### Option 3: Emoji/Icon Placeholder
If you want to use an emoji temporarily:
1. Comment out the local image line
2. Uncomment the emoji placeholder option
3. Change the emoji (🎤) to any emoji you prefer

## Creating a Logo

### Free Online Tools:
- **Canva**: https://www.canva.com (free templates)
- **Figma**: https://www.figma.com (professional design)
- **Adobe Express**: https://www.adobe.com/express (quick designs)
- **LogoMaker**: https://www.logomaker.com

### AI Tools:
- **DALL-E**: Create AI-generated logos
- **Midjourney**: Professional logo designs
- **Stable Diffusion**: Open-source AI image generation

### Logo Design Tips:
- ✅ Use microphone 🎤 or speech bubble 💬 icon
- ✅ Include text "TTS" or "TextToSpeech BD"
- ✅ Use vibrant colors (blue, purple, green work well)
- ✅ Keep it simple and recognizable
- ✅ Ensure it looks good in both light and dark modes
- ✅ Square format (1:1 ratio) works best

### Quick Start:
1. Create or download a logo image
2. Name it `logo.png`
3. Place it in this `assets` folder
4. The app will automatically display it at the top!

### Example Logo Ideas:
- Microphone with sound waves
- Speech bubble with "TTS" text
- Text "TextToSpeech BD" with icon
- Modern minimalist design with app colors
